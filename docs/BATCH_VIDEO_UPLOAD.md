# 批量视频上传发布功能使用说明

## 功能概述

批量上传本地视频文件，自动分配给选中的 TikTok 账号进行发布。视频将按顺序轮流分配给各个账号，实现多账号批量发布。

## 使用流程

### 1. 选择账号表

在下拉菜单中选择包含 TikTok 账号信息的数据表。

**必需字段**：
- `open_id` 或 `账号ID` - TikTok 账号的唯一标识
- `access_token` 或 `访问令牌` - TikTok API 访问令牌
- `username` 或 `用户名`（可选）- 账号显示名称

### 2. 选择发布账号

从加载的账号列表中选择要发布视频的账号（支持多选）。

**分配规则**：
- 视频将按顺序轮流分配给选中的账号
- 例如：选择了 3 个账号，上传 9 个视频
  - 视频1 → 账号1
  - 视频2 → 账号2
  - 视频3 → 账号3
  - 视频4 → 账号1
  - 视频5 → 账号2
  - ...以此类推

### 3. 上传视频文件

点击"选择视频文件"按钮，选择本地视频文件（支持多选）。

**支持格式**：
- MP4
- MOV
- AVI
- 其他常见视频格式

**文件大小**：
- 建议单个文件不超过 100MB
- 总上传大小受浏览器和服务器限制

### 4. 开始批量发布

点击"开始批量发布"按钮，系统将自动：
1. 将视频上传到阿里云 OSS
2. 调用 TikTok API 发布视频
3. 返回发布状态和 Publish ID

## 视频状态说明

| 状态 | 说明 |
|------|------|
| 待处理 | 视频已添加到列表，等待处理 |
| 上传中 | 正在上传到 OSS |
| 已上传 | 已上传到 OSS，准备发布 |
| 发布中 | 正在调用 TikTok API 发布 |
| 成功 | 发布成功，已获得 Publish ID |
| 失败 | 发布失败，查看错误信息 |

## 功能特点

### 1. 自动分配
- 视频自动轮流分配给选中的账号
- 无需手动指定每个视频的发布账号
- 支持多账号矩阵发布

### 2. 批量处理
- 一次上传多个视频
- 自动依次处理
- 实时显示进度

### 3. 状态跟踪
- 每个视频的处理状态实时更新
- 显示分配的账号
- 返回 Publish ID 用于后续查询

### 4. 错误处理
- 失败的视频显示错误信息
- 不影响其他视频的处理
- 可以重新处理失败的视频

## 注意事项

### 1. 账号 Token 有效性
- 确保账号的 `access_token` 有效
- Token 过期会导致发布失败
- 建议在发布前刷新 Token

### 2. 视频标题
- 默认使用文件名（去除扩展名）作为视频标题
- 建议使用有意义的文件名
- 例如：`产品介绍_20260302.mp4` → 标题：`产品介绍_20260302`

### 3. 发布设置
- 默认设置：
  - 隐私级别：公开（PUBLIC_TO_EVERYONE）
  - 允许评论：是
  - 允许合拍：是
  - 允许拼接：是

### 4. 上传速度
- 上传速度取决于网络状况
- 大文件上传时间较长，请耐心等待
- 建议在网络良好的环境下使用

### 5. 发布频率
- 系统会在每个视频之间延迟 1 秒
- 避免请求过快触发 TikTok 限流
- 大量视频发布可能需要较长时间

## 常见问题

### Q1: 上传失败怎么办？
**A**: 检查以下几点：
1. 文件格式是否支持
2. 文件大小是否超限
3. 网络连接是否正常
4. OSS 配置是否正确

### Q2: 发布失败怎么办？
**A**: 检查以下几点：
1. 账号 Token 是否有效
2. 账号是否有发布权限
3. 视频是否符合 TikTok 规范
4. 查看具体错误信息

### Q3: 如何查看发布结果？
**A**:
1. 成功的视频会显示 Publish ID
2. 可以复制 Publish ID
3. 在"发布"标签页中使用"更新发布状态"功能查询详细结果

### Q4: 可以中途取消吗？
**A**:
- 批量发布开始后无法中途取消
- 建议先测试少量视频
- 确认无误后再批量处理

### Q5: 视频会保存在哪里？
**A**:
- 视频上传到阿里云 OSS
- OSS 路径：`tiktok-batch-videos/时间戳_随机字符串.扩展名`
- 发布后视频存储在 TikTok 服务器

## 环境配置

### 必需的环境变量

在 `.env.production` 或 `.env.local` 中配置：

```bash
# 阿里云 OSS 配置
OSS_REGION=cn-qingdao
OSS_ACCESS_KEY_ID=your_access_key_id
OSS_ACCESS_KEY_SECRET=your_access_key_secret
OSS_BUCKET_NAME=your_bucket_name
OSS_ENDPOINT=oss-cn-qingdao.aliyuncs.com
OSS_CUSTOM_DOMAIN=your_custom_domain.com  # 可选
```

### API 配置

确保以下 API 可用：
- `/api/uploadFileDirect` - 上传文件到 OSS
- `/api/publishVideo` - 发布视频到 TikTok

## 最佳实践

### 1. 文件命名规范
```
产品名称_日期_序号.mp4
例如：iPhone15_20260302_001.mp4
```

### 2. 账号分组
- 将相似类型的账号分组
- 同一批视频发布到同一组账号
- 便于后续管理和分析

### 3. 分批处理
- 建议每批不超过 20 个视频
- 大量视频分多批处理
- 避免长时间占用浏览器

### 4. 测试流程
1. 先选择 1 个账号，上传 1 个视频测试
2. 确认成功后，逐步增加数量
3. 最后进行大批量处理

## 技术架构

### 前端
- React + TypeScript
- Semi UI 组件库
- 飞书多维表格 SDK

### 后端
- Next.js API Routes
- 阿里云 OSS SDK
- TikTok Business API

### 数据流
```
本地视频文件
    ↓
Base64 编码
    ↓
上传到 OSS
    ↓
获取 OSS URL
    ↓
调用 TikTok API
    ↓
返回 Publish ID
```

# 自评论发布功能使用说明

## 功能概述

给自己的 TikTok 视频批量发送评论，发送后自动验证评论是否成功。适用于新视频冷启动、增加互动、引导评论等场景。

## 使用场景

### 1. 新视频冷启动
- 新发布的视频缺少互动
- 通过自评论增加初始互动数据
- 提高视频推荐权重

### 2. 引导评论方向
- 发布引导性评论
- 设置讨论话题
- 营造互动氛围

### 3. 补充信息
- 补充视频中未提及的信息
- 添加链接或联系方式
- 回答常见问题

### 4. 测试功能
- 测试评论功能是否正常
- 验证账号权限
- 检查评论审核机制

## 使用流程

### 1. 选择账号表

在下拉菜单中选择包含 TikTok 账号信息的数据表。

**必需字段**：
- `access_token` 或 `访问令牌` - TikTok API 访问令牌

### 2. 选择账号

从账号表中选择要使用的账号（评论将以该账号身份发送）。

**注意**：
- 确保账号 Token 有效
- 账号需要有评论权限
- 建议使用自己的账号

### 3. 选择视频表

选择包含视频信息的数据表。

**必需字段**：
- `video_id` 或 `视频ID` - TikTok 视频的唯一标识
- 评论内容字段（自定义字段名）

**可选字段**：
- `title` 或 `标题` - 视频标题（用于显示）

### 4. 输入评论字段名

输入评论内容所在的字段名，例如：
- `评论内容`
- `comment`
- `自评论`

### 5. 加载视频和评论

点击"加载视频和评论"按钮，系统将：
- 读取视频表中的所有记录
- 提取 video_id 和评论内容
- 显示在任务列表中

### 6. 开始批量发送

点击"开始批量发送"按钮，系统将自动：
1. 发送评论到 TikTok
2. 等待 5 秒
3. 获取视频评论列表
4. 验证评论是否成功

## 评论状态说明

| 状态 | 说明 |
|------|------|
| 待发送 | 评论已加载，等待发送 |
| 发送中 | 正在调用 TikTok API 发送评论 |
| 已发送 | 评论已发送，等待验证 |
| 验证中 | 正在获取评论列表进行验证 |
| 成功 | 评论发送成功且已验证 |
| 失败 | 发送失败或验证失败 |

## 验证机制

### 验证方式

系统通过以下两种方式验证评论是否成功：

1. **Comment ID 匹配**
   - 发送评论后获得 comment_id
   - 在评论列表中查找相同的 comment_id

2. **评论内容匹配**
   - 如果 comment_id 匹配失败
   - 尝试匹配评论文本内容

### 验证时机

- 发送评论后等待 **5 秒**
- 给 TikTok 服务器处理时间
- 然后获取评论列表进行验证

### 验证结果

- ✅ **成功**：在评论列表中找到匹配的评论
- ❌ **失败**：未在评论列表中找到评论

## 功能特点

### 1. 自动验证
- 发送后自动验证
- 无需手动检查
- 实时反馈结果

### 2. 批量处理
- 一次处理多个视频
- 自动依次发送
- 实时显示进度

### 3. 状态跟踪
- 每个评论的处理状态实时更新
- 显示 Comment ID
- 显示错误信息

### 4. 错误处理
- 失败的评论显示错误信息
- 不影响其他评论的处理
- 可以重新处理失败的评论

## 注意事项

### 1. 账号权限
- 确保账号有评论权限
- Token 需要包含 `comment.list` 和 `comment.list.manage` 权限
- Token 过期会导致发送失败

### 2. 评论内容
- 遵守 TikTok 社区规范
- 避免敏感词汇
- 不要发送垃圾评论
- 建议评论内容有意义

### 3. 发送频率
- 系统会在每个评论之间延迟 2 秒
- 避免请求过快触发限流
- 大量评论发送可能需要较长时间

### 4. 验证延迟
- 发送后等待 5 秒再验证
- 如果验证失败，可能是延迟问题
- 可以手动检查评论是否实际发送成功

### 5. 自评论限制
- TikTok 可能对自评论有限制
- 过多自评论可能被识别为异常行为
- 建议适度使用

## 常见问题

### Q1: 发送失败怎么办？
**A**: 检查以下几点：
1. 账号 Token 是否有效
2. 账号是否有评论权限
3. video_id 是否正确
4. 评论内容是否符合规范
5. 查看具体错误信息

### Q2: 验证失败但评论实际发送成功？
**A**: 可能原因：
1. TikTok 服务器延迟，5 秒不够
2. 评论被审核，暂时不显示
3. 评论列表 API 返回不完整
4. 建议手动检查视频评论

### Q3: 可以给别人的视频发评论吗？
**A**:
- 技术上可以
- 但本功能主要用于自己的视频
- 给别人视频发评论需要注意礼貌和规范

### Q4: 评论会被删除吗？
**A**:
- 如果违反社区规范，可能被删除
- 如果被识别为垃圾评论，可能被删除
- 建议发送有意义的评论

### Q5: 可以中途取消吗？
**A**:
- 批量发送开始后无法中途取消
- 建议先测试少量评论
- 确认无误后再批量处理

## 最佳实践

### 1. 评论内容建议

**引导性评论**：
```
"大家觉得这个方法怎么样？"
"有没有遇到类似的问题？"
"欢迎在评论区分享你的经验"
```

**补充信息**：
```
"视频中提到的链接：[链接]"
"更多详细信息可以私信我"
"完整教程在我的主页"
```

**互动引导**：
```
"点赞收藏不迷路"
"关注我了解更多"
"下期想看什么内容？"
```

### 2. 发送时机

- 视频发布后 **1-2 小时** 内发送
- 避免视频刚发布就有大量评论（不自然）
- 分批发送，间隔一段时间

### 3. 数量控制

- 每个视频建议 **1-3 条** 自评论
- 不要超过 5 条
- 过多自评论会显得不自然

### 4. 内容多样化

- 不要所有视频都用相同的评论
- 根据视频内容定制评论
- 使用不同的表达方式

# 系统使用说明

## 1. 用户密钥与积分系统

### 1.1 数据库表

**表名**: `users`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| api_key | VARCHAR(64) | 用户密钥（唯一） |
| credits | INT | 剩余积分 |
| remark | VARCHAR(200) | 备注（lark:{userId} 或 url:{URL}） |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |

### 1.2 积分规则

- AI 视频生成（Sora2）：消耗 10 积分/次
- Nano 图像生成：消耗 2 积分/次
- 新用户注册：赠送 10 积分

### 1.3 密钥生成逻辑

1. **优先飞书用户**: 通过飞书 userId 生成密钥，存入数据库
2. **URL 降级方案**: 非飞书环境时，根据 URL 生成一致密钥（用于测试/本地）

## 2. API 接口

### 2.1 用户初始化

**接口**: `POST /api/initUser`

**请求参数**:
```json
{
  "user_id": "飞书用户ID"  // 可选
}
```
或
```json
{
  "url": "页面URL"  // 可选
}
```

**响应**:
```json
{
  "code": 0,
  "data": {
    "api_key": "用户密钥",
    "credits": 10
  }
}
```

### 2.2 查询积分

**接口**: `POST /api/checkCredits`

**请求参数**:
```json
{
  "api_key": "用户密钥",
  "cost": 0  // 消耗积分（0表示只查询）
}
```

**响应**:
```json
{
  "code": 0,
  "data": {
    "credits": 10,
    "enough": true
  }
}
```

### 2.3 充值（内部接口）

**接口**: `POST /api/internal/recharge`

**调用方式**:
```bash
curl -X POST https://your-domain.com/api/internal/recharge \
  -H "Content-Type: application/json" \
  -H "x-recharge-secret: recharge_2024_secure_key" \
  -d '{
    "api_key": "用户密钥",
    "amount": 100,
    "remark": "微信转账"
  }'
```

**请求参数**:
| 参数 | 必填 | 说明 |
|------|------|------|
| api_key | 是 | 用户密钥 |
| amount | 是 | 充值积分数量（正整数） |
| remark | 否 | 备注（如充值方式） |

**响应**:
```json
{
  "code": 0,
  "data": {
    "credits": 110,
    "action": "updated"  // 或 "created"（新建用户）
  }
}
```

**密钥**: `x-recharge-secret` header，必须与 `.env.local` 中的 `RECHARGE_SECRET` 一致

## 3. 常见问题

### 3.1 充值流程

1. 客户提供密钥（或从数据库查找）
2. 客户转账后，在服务器执行充值：
   ```bash
   curl -X POST https://your-domain.com/api/internal/recharge \
     -H "Content-Type: application/json" \
     -H "x-recharge-secret: recharge_2024_secure_key" \
     -d '{"api_key": "客户密钥", "amount": 100, "remark": "微信转账100元"}'
   ```
3. 客户点击前端"刷新"按钮，同步最新积分

# 素材库「到了设定发布时间自动发布」说明

## 当前实现方式

### 方式一：前端定时检查（已实现）

在 **发布** 页中已提供 **「定时自动发布」** 开关：

- **开启后**：每 10 分钟自动执行一次与「自动发布」相同的逻辑，筛选「发布状态 = 等待发布」且「发布时间 ≤ 当前时间」的素材并发布。
- **首次检查**：开启开关后约 1 分钟进行第一次检查，之后按 10 分钟间隔执行。
- **前提**：需要**保持飞书多维表格边栏/本页面处于打开状态**（浏览器标签或飞书客户端不关闭），到点后会自动发布，无需再手动点击「自动发布」。

使用步骤：

1. 在素材库中把需要定时发布的记录设为「发布状态」= **等待发布**，并填好「发布时间」「发布账号」、视频附件等。
2. 打开边栏的 **发布** 页，选择好「素材库表」和「账号列表」。
3. 打开 **「定时自动发布」** 开关。
4. 保持该多维表格/边栏打开，到设定时间后系统会自动检查并发布。

---

### 方式二：服务端定时任务（需自行扩展）

若希望**不依赖用户打开页面**、在后台到点自动发布，需要由服务端定期执行发布逻辑，例如：

1. **新增 API 接口**（如 `POST /api/cron/autoPublish`）  
   - 在服务端通过 **飞书开放平台 Open API**（需 `app_token`）读取多维表格「素材库」数据。  
   - 筛选条件：发布状态 = 等待发布，发布时间 ≤ 当前时间。  
   - 对每条记录：取视频附件临时链接 → 上传到 OSS → 调用现有 `publishVideo` 接口 → 再通过 Open API 回写「发布状态」等字段。

2. **配置定时触发**  
   - 使用平台提供的定时能力（如 Vercel Cron、Replit 定时任务）或外部 cron 服务（如 cron-job.org）每 5～15 分钟请求一次该 API。

3. **环境与权限**  
   - 需在飞书开放平台创建应用并拿到 `app_id`、`app_secret`，以及对应多维表格的 `base_id`。  
   - 服务端用 `app_token` 调用 [多维表格 Open API](https://open.feishu.cn/document/server-docs/docs/bitable-v1/app-table-record/list) 读写表格，实现与当前前端「自动发布」相同的业务逻辑。

当前项目为**边栏插件**，表数据通过前端 `@lark-base-open/js-sdk` 访问，未包含上述服务端 Open API 与 cron 代码；若需「关掉页面也能到点发布」，需按上述思路自行实现服务端与定时任务。

# 获取访问令牌

TikTok 账号用户授权后，您会收到的授权码，您可向以下接口发送请求，获取后续申请访问接口所需的 TikTok 账号访问令牌以及用于刷新访问令牌的 TikTok 账号刷新令牌。

欲获取 TikTok 账号用户授予的 TikTok 账号权限范围信息，可将生成的访问令牌传入 `/tt_user/token_info/get/` 接口进行查询。

---

## 访问令牌到期

TikTok 账号访问令牌的有效期为 **1 天**。TikTok 账号访问令牌到期后，您需要向此接口发送请求，以刷新访问令牌。发送令牌刷新请求时，请传入刷新令牌（`refresh_token`）。

## 刷新令牌到期

TikTok 账号刷新令牌的有效期为 **1 年**。如果刷新令牌到期，开发者需要向用户发送请求，通过用户授权流程对应用重新授权。

---

## 获取、刷新或撤销 TikTok 账号访问令牌

| 操作 | 接口 | 说明 |
|------|------|------|
| 获取访问令牌 | `/tt_user/oauth2/token/` | 需传入 `redirect_uri`，以提升安全性 |
| 刷新访问令牌 | `/tt_user/oauth2/refresh_token/` | 使用刷新令牌获取新的访问令牌 |
| 撤销访问令牌 | `/tt_user/oauth2/revoke/` | 撤销已授权的访问令牌 |

---

## 获取 TikTok 账号访问令牌

您可以使用本接口获取 TikTok 账号访问令牌。

### 请求

| 项目 | 值 |
|------|-----|
| **地址** | `https://business-api.tiktok.com/open_api/v1.3/tt_user/oauth2/token/` |
| **方法** | POST |

#### Header

| 字段 | 类型 | 描述 |
|------|------|------|
| Content-Type | string | **必填**。请求消息类型。允许格式：`application/json`。 |

#### 参数

| 字段 | 类型 | 描述 |
|------|------|------|
| client_id | string | **必填**。开发者应用 ID。若想获取应用 ID，可以导航至 **应用管理 > App Detail > 基本信息**。 |
| client_secret | string | **必填**。开发者应用密钥。若想获取密钥，可以导航至 **应用管理 > App Detail > 基本信息**。 |
| grant_type | string | **必填**。生成访问令牌的方式。允许的枚举值：`authorization_code` - 通过授权码生成访问令牌。 |
| auth_code | string | **必填**。您的 TikTok 账户授权 URL 生成的授权码（auth_code）。授权码有效期为 10 分钟且只能使用一次。若想了解您使用的 API 类别对应的授权码获取方式，可查看不同 API 的授权流程对比中的"OAuth 授权 URL"行。 |
| redirect_uri | string | **必填**。客户将跳转的重定向 URL。传入的值必须和开发者应用中的 TikTok 账户持有人重定向 URL 保持一致。 |

### 示例

```bash
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/tt_user/oauth2/token/' \
--header 'Content-Type: application/json' \
--data '{
    "client_id":"{{client_id}}",
    "client_secret":"{{client_secret}}",
    "grant_type":"authorization_code",
    "auth_code":"{{auth_code}}",
    "redirect_uri":"{{redirect_uri}}"
}'
```

### 返回

| 字段 | 类型 | 描述 |
|------|------|------|
| code | number | 返回码。完整返回码列表及描述，可查看附录 - 返回码。 |
| message | string | 返回信息。更多信息可查看附录 - 返回码。 |
| request_id | string | 请求的日志 ID，唯一标识一个请求。 |
| data | object | 返回数据。 |
| data.access_token | string | 用于权限验证的短期访问令牌。该令牌有效期为 1 天。 |
| data.token_type | string | 令牌类型。枚举值：`Bearer` - 不记名令牌，拥有该令牌后任何人均可访问相关资源。 |
| data.scope | string | 该访问令牌所拥有的权限。 |
| data.expires_in | number | 访问令牌的剩余有效时长，以秒为单位。 |
| data.refresh_token | string | 用于刷新访问令牌的刷新令牌。刷新令牌有效期为 1 年。**注意：请保留此字段，用于刷新 access_token。** |
| data.refresh_token_expires_in | number | 刷新令牌的剩余有效时长，以秒为单位。 |
| data.open_id | string | TikTok 账户的应用唯一识别 ID。 |

### 示例

```json
HTTPS/1.1 200 OK
{
    "code": 0,
    "message": "OK",
    "request_id": "{{request_id}}",
    "data": {
        "access_token": "{{access_token}}",
        "expires_in": 86400,
        "open_id": "{{open_id}}",
        "refresh_token": "{{refresh_token}}",
        "refresh_token_expires_in": 31536000,
        "scope": "message.list.manage,video.list,video.insights,user.insights,user.info.basic,comment.list,biz.brand.insights,biz.spark.auth,tcm.order.update,comment.list.manage,video.upload,video.publish,biz.ads.recommend,user.account.type,biz.creator.info,user.info.username,message.list.send,user.info.profile,user.info.stats,message.list.read,biz.creator.insights",
        "token_type": "Bearer"
    }
}
```

## 刷新 TikTok 账号访问令牌

您可以通过本接口使用 TikTok 账号刷新令牌刷新访问令牌。

### 请求

| 项目 | 值 |
|------|-----|
| **地址** | `https://business-api.tiktok.com/open_api/v1.3/tt_user/oauth2/refresh_token/` |
| **方法** | POST |

#### Header

| 字段 | 类型 | 描述 |
|------|------|------|
| Content-Type | string | **必填**。请求消息类型。允许格式：`application/json`。 |

#### 参数

| 字段 | 类型 | 描述 |
|------|------|------|
| client_id | string | **必填**。开发者应用 ID。若想获取应用 ID，可以导航至 **应用管理 > App Detail > 基本信息**。 |
| client_secret | string | **必填**。开发者应用密钥。若想获取密钥，可以导航至 **应用管理 > App Detail > 基本信息**。 |
| grant_type | string | **必填**。生成访问令牌的方式。允许的枚举值：`refresh_token` - 通过刷新令牌生成访问令牌。 |
| refresh_token | string | **必填**。刷新令牌，用于刷新现有的访问令牌。您可在使用 `/tt_user/oauth2/token/` 生成访问令牌时的返回中获取刷新令牌。 |

### 示例

```bash
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/tt_user/oauth2/refresh_token/' \
--header 'Content-Type: application/json' \
--data '{
    "client_id":"{{client_id}}",
    "client_secret":"{{client_secret}}",
    "grant_type":"refresh_token",
    "refresh_token":"{{refresh_token}}"
}'
```

| code | number | 返回码。完整返回码列表及描述，可查看附录 - 返回码。 |

| data | object | 返回数据。 |
| data.access_token | string | 用于权限验证的短期访问令牌。该令牌有效期为 1 天。 |
| data.token_type | string | 令牌类型。枚举值：`Bearer` - 不记名令牌，拥有该令牌后任何人均可访问相关资源。 |
| data.scope | string | 该访问令牌所拥有的权限。 |
| data.expires_in | number | 访问令牌的剩余有效时长，以秒为单位。 |
| data.refresh_token | string | 用于刷新访问令牌的刷新令牌。刷新令牌有效期为 1 年。**注意：请保留此字段，用于刷新 access_token。** |
| data.refresh_token_expires_in | number | 刷新令牌的剩余有效时长，以秒为单位。 |
| data.open_id | string | TikTok 账户的应用唯一识别 ID。 |

## 撤销 TikTok 账号访问令牌

您可以使用本接口撤销 TikTok 账号访问令牌。

### 请求

| 项目 | 值 |
|------|-----|
| **地址** | `https://business-api.tiktok.com/open_api/v1.3/tt_user/oauth2/revoke/` |
| **方法** | POST |

#### Header

| 字段 | 类型 | 描述 |
|------|------|------|
| Content-Type | string | **必填**。请求信息类型。允许格式：`application/json`。 |

#### 参数

| 字段 | 类型 | 描述 |
|------|------|------|
| client_id | string | **必填**。开发者应用 ID。若想获取应用 ID，您可以导航至 **应用管理 > App Detail > 基本信息**。 |
| client_secret | string | **必填**。开发者应用密钥。若想获取密钥，您可以导航至 **应用管理 > App Detail > 基本信息**。 |
| access_token | string | **必填**。您想要撤销的 TikTok 账号访问令牌。您可使用 `/tt_user/oauth2/token/` 创建新的访问令牌，或使用 `/tt_user/oauth2/refresh_token/` 获取刷新后的访问令牌。 |

### 示例

```bash
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/tt_user/oauth2/revoke/' \
--header 'Content-Type: application/json' \
--data '{
    "client_id":"{{client_id}}",
    "client_secret":"{{client_secret}}",
    "access_token":"{{access_token}}"
}'
```

### 返回

| 字段 | 类型 | 描述 |
|------|------|------|
| code | number | 返回码。完整返回码列表及描述，参见 附录 - 返回码。 |
| message | string | 返回信息。更多信息参见 附录 - 返回码。 |
| request_id | string | 请求的日志 ID，唯一标识一个请求。 |
| data | object | 返回数据。 |

### 示例

```json
HTTPS/1.1 200 OK
{
    "code": 0,
    "message": "OK",
    "request_id": "{{request_id}}",
    "data": {}
}
```

# 获取账号主页数据

获取 TikTok 账号主页数据。

您可以使用本接口获取有关 TikTok 账号粉丝群体和主页互动的详细分析和洞察。

> **注意**
> 
> - 部分主页层级指标有 24-48 小时的延迟。本接口数据延迟可查看返回参数表中的字段描述，或查看账号洞察数据延迟-数据延迟参照表。
> - 您可通过 `/business/get/` 接口获取的数据受对应的 TikTok Analytics 数据影响。TikTok Analytics 数据可在 TikTok 应用或 https://www.tiktok.com/analytics 查看。若对应指标数据在 TikTok Analytics 不存在，您将无法通过获取相应数据。若想获取洞察及 Analytics 数据，TikTok 账号所有者需首先发布至少一个视频，随后点击手机端 TikTok App 的 Analytics 界面的 "Turn On"（启用）按钮。
> - 您通过 `/business/get/` 接口的 `video_views` 字段获取的视频播放次数为总播放次数，即自然流量产生的视频播放次数和付费流量产生的视频播放次数之和。

以下表格概括了 v1.2 与 v1.3 接口的变化。

## 请求

| 项目 | 值 |
|------|-----|
| **地址** | `https://business-api.tiktok.com/open_api/v1.3/business/get/` |
| **方法** | GET |

### Header

| 字段 | 类型 | 描述 |
|------|------|------|
| Access-Token | string | **必填**。经 TikTok 创作者授权的访问令牌。若想获取访问令牌，需使用 `/tt_user/oauth2/token/` 接口。 |

### 参数

请将下列参数作为查询字符串进行传递。

| 字段 | 类型 | 描述 |
|------|------|------|
| business_id | string | **必填**。TikTok 账户的应用唯一识别 ID。您需将 `/tt_user/oauth2/token/` 接口返回的 `open_id` 字段值传给本字段。 |
| start_date | string | 查询起始日期（闭区间）。格式如下：`2021-06-01`。日期基于 UTC 时区。若不进行设置，`start_date` 将为 [当前日期 - 7 天]。支持的最长回溯期为 60 天。 |
| end_date | string | 查询结束日期（闭区间）。格式如下：`2021-06-01`。日期基于 UTC 时区。若不进行设置，`end_date` 将为 [当前日期 - 1 天]。 |
| fields | string[] | 请求字段。若不进行设置，仅返回默认字段。默认值：`["display_name", "profile_image"]`。 |

### fields 支持字段

| 字段 | 描述 | 所需权限 |
|------|------|----------|
| is_business_account | 该 TikTok 账户是否为 TikTok 企业号 | user.account.type |

| videos_count | TikTok 账号发布的公开视频总数 | user.info.stats |
| video_views | 每日观看次数。您的视频的每日观看次数 | user.insights |
| unique_video_views | 每日触达的观众。每日至少观看过一次已发布内容的用户 | user.insights |
| profile_views | 每日个人主页访问量。每日用户查看您的个人主页的次数 | user.insights |
| likes | 每日点赞数。每日用户对已发布视频的点赞次数 | user.insights |
| comments | 每日评论数。每日用户对已发布视频的评论次数 | user.insights |
| shares | 每日分享次数。每日用户对已发布视频的分享次数 | user.insights |
| phone_number_clicks | 每日手机号码点击数 | user.insights |
| lead_submissions | 每日潜在客户提交次数 | user.insights |
| app_download_clicks | 每日应用下载链接点击数 | user.insights |

| email_clicks | 每日邮箱点击数 | user.insights |
| address_clicks | 每日地址点击数 | user.insights |
| daily_total_followers | 每日净增长。表示在一定时段内每日关注您账号的用户数 | user.insights |
| daily_new_followers | 每日新粉丝数。表示在一定时段内每日获得的新粉丝总数 | user.insights |
| daily_lost_followers | 每日掉粉数。表示在一定时段内每日失去的粉丝总数 | user.insights |
| audience_activity | 每小时粉丝活动（仅粉丝数至少为 100 的账号） | user.insights |
| engaged_audience | 每日互动的观众。每日与您发布的至少一项内容有过互动的用户 | user.insights |
| audience_ages | 粉丝年龄分布（仅粉丝数至少为 100 的账号） | user.insights |
| audience_genders | 粉丝性别分布（仅粉丝数至少为 100 的账号） | user.insights |
| audience_countries | 粉丝热门国家/地区（仅粉丝数至少为 100 的账号） | user.insights |
| audience_cities | 粉丝热门城市（仅粉丝数至少为 100 的账号） | user.insights |

# 发布视频

将公开视频帖子发布到自有账号。

你可以使用本接口将公开视频帖子发布到自有 TikTok 账号。

你需要传入要发布的视频，并可以选择传入视频标题，以及是否启用不同形式的用户互动（评论/拼接/合拍）。

若想了解可订阅的帖子发布 Webhook 事件，请查看帖子发布事件。若想为你的开发者应用配置 Webhook 回调 URL，需使用 Webhook API 接口 `/business/webhook/update/`。

> **注意**
> 
> - 为鼓励真实分享，防止滥发帖子，TikTok 限制了通过该接口为每个 TikTok 账号发布视频帖子的数量：**每分钟最多发布 6 个视频帖子，每天最多发布 15 个视频帖子**。
> - 将视频发布到你的 TikTok 账号后，你可能会发现，在账号主页查看或下载帖子时，其分辨率和比特率与原视频文件相比有所降低。这是因为在视频转码的过程中，设备显示能力和网络状况等因素会导致分辨率和比特率发生变化。

## 请求

| 项目 | 值 |
|------|-----|
| **地址** | `https://business-api.tiktok.com/open_api/v1.3/business/video/publish/` |
| **方法** | POST |

### Header

| 字段 | 类型 | 描述 |
|------|------|------|
| Access-Token | string | **必填**。经 TikTok 达人授权的访问令牌。若想获取访问令牌，需使用 `/tt_user/oauth2/token/` 接口。 |
| Content-Type | string | **必填**。请求信息类型。允许格式：`application/json`。 |

### 参数

| 字段 | 类型 | 参数位置 | 描述 |
|------|------|----------|------|
| business_id | string | Body | **必填**。TikTok 账号的开发者应用唯一识别 ID。需将 `/tt_user/oauth2/token/` 接口返回的 `open_id` 字段值传入本字段。 |
| video_url | string | Body | **必填**。用于发布视频内容的可公开访问 HTTP(s) URL，建议 TTL 至少为 30 分钟。 |
| custom_thumbnail_url | string | Body | 用作视频封面图片的自定义图片的可公开访问 HTTP(s) URL。当传入 `custom_thumbnail_url` 时，`thumbnail_offset` 将被忽略。 |
| post_info | object | Body | **必填**。帖子相关信息。此为必填字段，即使你不想使用 `post_info` 中的其他任何参数。在这一情况下，将此字段设置为空对象 (`{}`)。 |
| music_sound_info | object | Body | 要用于视频的商用音乐（曲目）的信息。 |

#### video_url 视频限制

- 音视频内容必须采用 `.mp4`、`.mov` 或 `.webm` 格式
- 视频大小上限为 **1 GB**
- 视频时长不得少于 **3 秒**，不得超过 **600 秒**
- 视频高度和宽度不得低于 **360 px**
- 视频帧率不得低于 **23 FPS**，不得高于 **60 FPS**

若想查询允许 TikTok 账号发布的最大视频时长，需使用 `/business/video/settings/` 接口，并查看返回的 `max_video_post_duration_sec`。

**示例：** `https://www.example.com/tiktok-videos/video.mp4`

> **重要说明**
> 
> - 自 2023 年 11 月 16 日起，你无法再使用未经验证的视频 URL 发布视频。为确保顺利集成 API，建议你尽快验证 URL 资源的所有权，并传入已手动或自动验证所有权的 URL。
> - 若想手动验证 URL 资源的所有权，请按照管理 URL 资源中所述的步骤操作。
> - 2023 年 11 月 16 日之后，如果你想通过 `/business/video/publish/` 接口使用无需验证的测试视频 URL 发布测试视频，可使用测试 URL：
>   ```
>   https://sf16-va.tiktokcdn.com/obj/eden-va2/uvpapzpbxjH-aulauvJ-WV[[/ljhwZthlaukjlkulzlp/3min.mp4
>   ```

#### custom_thumbnail_url 图片限制

- 最高分辨率：**1080 x 1920 px** 或 **1920 x 1080 px**
- 最低分辨率：**360 x 360 px**
- 文件大小：不超过 **20 MB**
- 文件类型：**JPG、JPEG、WebP 或 PNG**

**示例：** `https://www.example.com/tiktok-images/image.png`

> **注意**：传入已手动或自动验证所有权的 URL。若想手动验证 URL 资源的所有权，请按照管理 URL 资源中所述的步骤操作。

#### post_info 对象

| 字段 | 类型 | 描述 |
|------|------|------|
| caption | string | 视频标题/描述 - 可以包含自有 TikTok 账号好友（互关）的 #hashtags 和 @mentions。你可以使用 `\n` 作为换行符。长度限制：**2,200 个字符**（UTF-16 编码），最多提及 **30 条**。示例：`Me and me casa 🏠 #cat #kitten #britishshorthair` |
| is_brand_organic | boolean | **必填**。是否为视频启用品牌自然流量内容开关。如果将此字段设置为 `true`，视频将被标记为品牌自然流量内容，表示你在推广自己的品牌或业务。视频将添加"推广内容"标签。**注意：** 如果将 `is_brand_organic` 和 `is_branded_content` 都设置为 `true`，`is_brand_organic` 将被忽略，视频将被标记为品牌内容。 |
| is_branded_content | boolean | **必填**。是否为视频启用品牌内容开关。如果将此字段设置为 `true`，视频将被标记为品牌内容，表示你与品牌存在付费合作关系。视频将添加"品牌内容"标签。 |
| tto_invite_link | string | TTO Creator Marketplace 营销活动的邀请链接。仅当同时满足以下所有条件时合法：`is_branded_content` 设置为 `true`；TikTok 账号（达人）已受邀加入 TikTok One (TTO) Creator Marketplace 营销活动；TikTok 账号已加入营销活动。 |
| disable_comment | boolean | 是否禁用已发布的视频帖子的"允许评论"设置。支持的值：`false`（启用该设置）、`true`（禁用该设置）。默认值：`false`。 |
| disable_duet | boolean | 是否禁用已发布的视频帖子的"允许合拍"设置。支持的值：`false`（启用该设置）、`true`（禁用该设置）。默认值：`false`。 |
| disable_stitch | boolean | 是否禁用已发布的视频帖子的"允许拼接"设置。支持的值：`false`（启用该设置）、`true`（禁用该设置）。默认值：`false`。 |
| thumbnail_offset | integer | 用于选择已发布视频中的一帧作为封面图片的设置，格式为时间戳（单位：毫秒）。示例：`8000`。默认值：`0`。**注意：** 当传入 `custom_thumbnail_url` 时，`thumbnail_offset` 将被忽略。 |
| is_ai_generated | boolean | 是否为视频帖子启用 AI 生成内容开关。如果启用该开关，视频发布后将添加"创作者标记为 AI 生成"标签，并且无法更改。支持的值：`true`、`false`。默认值：`false`。 |
| upload_to_draft | boolean | 是否将帖子上传为草稿。支持的值：`true`、`false`。默认值：`false`。如果将此字段设置为 `true`，`post_info` 内的其他所有字段将被忽略。 |
| is_ads_only | boolean | 是否将视频发布为"仅在广告中显示"的视频。支持的值：`true`（将视频发布为广告，不公开显示在你的主页中）、`false`（不将视频发布为广告）。默认值：`false`。 |

#### music_sound_info 对象

| 字段 | 类型 | 描述 |
|------|------|------|
| music_sound_id | string | **条件必填**（使用 `music_sound_info` 时必填）。要用于视频的商用音乐 ID。你可以使用 `/discovery/cml/trending_list/` 接口获取此 ID。 |
| music_sound_volume | integer | **条件必填**（使用 `music_sound_info` 时必填）。商用音乐的音量。默认值：`0`。值范围：`0-100`。**注意：** 使用 TikTok 应用时，默认音量为 50。 |
| music_sound_start | integer | 视频所用音乐的起始时间点，单位为毫秒。如果未提供，此字段默认设置为 `0`（曲目的开头）。 |
| music_sound_end | integer | 视频所用音乐的结束时间点，单位为毫秒。如果未提供，此字段默认设置为视频的完整时长。 |
| video_original_sound_volume | integer | 原视频的背景音量。默认值：`0`。值范围：`0-100`。**注意：** 使用 TikTok 应用时，默认音量为 50。 |

## 示例

```bash
curl -L -X POST 'https://business-api.tiktok.com/open_api/v1.3/business/video/publish/' \
-H 'Content-Type: application/json' \
-H 'Access-Token: 1234a16d2e08c3f17d1984a1be07d00406p3LIAF7vEpxliox8GRpCINv70x' \
--data-raw '{
  "business_id": "20f5994f-4a67-44d4-a48f-2ce494a853b8",
  "video_url": "https://s3.amazonaws.com/tiktok-videos/video.mp4",
  "post_info": {
      "caption": "Me and me casa 🏠 #cat #kitten #britishshorthair",
      "disable_comment": false,
      "disable_duet": false,
      "disable_stitch": false
  }
}'
```

## 返回

### Header

这些 Header 对于问题报告和排查非常重要，需要记录。

| 字段 | 类型 | 描述 |
|------|------|------|
| Date | string | 收到返回结果时的日期和时间 (GMT)。示例：`Fri, 13 Aug 2021 08:04:42 GMT` |
| X-Tt-Logid | string | API 请求的唯一识别 ID。 |

### Body

| 字段 | 类型 | 描述 |
|------|------|------|
| request_id | string | API 请求的唯一识别 ID。请记录所有 API 请求的唯一识别 ID。此字段对于问题报告和排查非常重要。 |
| code | Integer | 返回码。完整返回码列表及描述参见附录 - 返回码。 |
| message | string | 返回信息。更多信息参见附录 - 返回信息。 |
| data | object | 返回数据。 |
| data.share_id | string | 视频帖子发布任务的唯一识别 ID。你可以在 `/business/publish/status/` 接口中将此 ID 用作 `publish_id`，查询视频帖子的发布状态。示例：`v_pub_url~v1.2345123456789123456` |

> **注意**
> 
> - 用于已分享视频内容的视频发布状态 Webhook 将包含此开发者应用识别 ID，以监测视频上传的状态。视频发布完成后，成功运行的 Webhook 也将包含为该视频新建的唯一识别 ID，该识别 ID 可用于获取视频洞察。
> - 若想为你的开发者应用配置 Webhook 回调 URL，需使用 Webhook API 接口 `/business/webhook/update/`。

# 获取推荐标签

为 TikTok 账号获取推荐话题标签。

您可以使用本接口传入关键词，从而为您的 TikTok 账号视频获取推荐话题标签列表。

返回的话题标签（`name`）可在使用 `/business/video/publish/` 将视频发布到 TikTok 账号时，用在 `caption` 字段中作为视频文案中的一部分。

> **注意**：本接口为 1.3 版本中的新接口。

---

## 请求

| 项目 | 值 |
|------|-----|
| **地址** | `https://business-api.tiktok.com/open_api/v1.3/business/hashtag/suggestion/` |
| **方法** | GET |

### Header

| 字段 | 类型 | 描述 |
|------|------|------|
| Access-Token | string | **必填**。经 TikTok 创作者授权的访问令牌。若想获取访问令牌，需使用 `/tt_user/oauth2/token/` 接口。 |

### 参数

请将下列参数作为查询字符串进行传递。

| 字段 | 类型 | 描述 |
|------|------|------|
| business_id | string | **必填**。TikTok 账户的应用唯一识别 ID。您需将 `/tt_user/oauth2/token/` 接口返回的 `open_id` 字段值传给本字段。 |
| keyword | string | **必填**。要获取对应推荐话题标签的关键词。 |
| language | string | 关键词语言。推荐话题标签的语言将与指定的关键词语言一致。默认值：`en`（英语）。 |

## 示例

```bash
curl --location --request GET 'https://business-api.tiktok.com/open_api/v1.3/business/hashtag/suggestion/?business_id={{business_id}}&keyword=summer&language=en' \
  --header 'Access-Token: {{Access-Token}}'
```

---

## 返回

### Header

这些 header 很重要，可用于记录问题报告和故障排查信息。

| 字段 | 类型 | 描述 |
|------|------|------|
| Date | string | 收到返回时的 (GMT) 日期和时间。示例：`Fri, 13 Aug 2021 08:04:42 GMT` |
| X-Tt-Logid | string | 接口请求的唯一标识符。 |

### Body

| 字段 | 类型 | 描述 |
|------|------|------|
| request_id | string | 接口请求的唯一标识符。请记录此字段，用于所有接口请求。此字段对于问题报告和故障排查十分重要。 |
| code | integer | 返回码。完整返回码列表及描述，可查看附录 - 返回码。 |
| message | string | 返回信息。更多信息可查看附录 - 返回码。 |
| data | object | 返回数据。 |
| data.suggestions | object[] | 推荐话题标签列表。共计返回十个推荐话题标签，话题标签先按精确匹配，其次按照浏览量排序。 |

### suggestions 对象

| 字段 | 类型 | 描述 |
|------|------|------|
| name | string | 推荐的话题标签名称。 |
| view_count | integer | 推荐的话题标签对应的浏览量。 |

> **注意**
> 
> 若针对您传入的关键词无法匹配到推荐话题标签，将在 `name` 字段返回传入的关键词，且 `view_count` 将显示为 `0`。

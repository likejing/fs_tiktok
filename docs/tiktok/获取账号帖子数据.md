# 获取账号帖子数据

获取 TikTok 账号帖子数据。

您可以使用本接口获取 TikTok 账号公开的视频、图片或文本帖子的覆盖人数和互动数据。返回的视频帖子列表包括展示在账户主页的原生视频，以及"只作为广告展示"的帖子（即专门用作公开可访问的广告、但不展示在账户主页的视频帖子）。

结果会分页显示。您可以使用 `max_count` 请求参数，指定返回中每页返回的帖子最大数量。

> **注意**
> 
> - 部分主页层级指标有 24-48 小时的延迟。本接口数据延迟可查看返回参数表中的字段描述，或查看账号洞察数据延迟-数据延迟参照表。
> - 帖子上传 365 天后，将停止更新帖子数据。
> - 您可通过 `/business/video/list/` 接口获取的数据受对应的 TikTok Analytics 数据影响。TikTok Analytics 数据可在 TikTok 应用或 https://www.tiktok.com/analytics 查看。若对应指标数据在 TikTok Analytics 不存在，您将无法通过获取相应数据。若想获取洞察及 analytics 数据，TikTok 账号所有者需首先发布至少一个视频，随后点击手机端 TikTok App 的 Analytics 界面的 "Turn On"（启用）按钮。
> - 您通过 `/business/video/list/` 接口的 `video_views` 字段获取的视频播放次数为总播放次数，即自然流量产生的视频播放次数和付费流量产生的视频播放次数之和。
> - 若未返回 `reach`、`full_video_watched_rate`、`total_time_watched`、`average_time_watched`、`impression_sources` 和 `audience_countries` 字段的数据，通常是由于对应的视频连续超过 7 天处于不活跃状态（未被观看、点赞、评论或分享）。欲获取这些字段的数据，您可以观看、点赞、评论或分享该处于不活跃状态的视频，并在 24-48 小时后重试。
> - 若有的帖子未返回，很可能是因为帖子由于违反了 TikTok 相关规定，例如违反了 TikTok 音乐版权规定，而被筛选掉。

## v1.2 与 v1.3 版本对比

以下表格概括了 v1.2 与 v1.3 接口的变化。

| 变化内容 | v1.2 | v1.3 |
|----------|------|------|
| 接口路径 | `/v1.2/business/videos/list/` | `/v1.3/business/video/list/` |
| 方法 | POST | GET |
| 新增返回参数 | / | `favorites`, `profile_views`, `website_clicks`, `phone_number_clicks`, `lead_submissions`, `app_download_clicks`, `email_clicks`, `address_clicks`, `video_view_retention`, `audience_genders`, `audience_cities`, `audience_types`, `new_followers`, `engagement_likes`, `ad_post_only`, `media_type` |

## 请求

| 项目 | 值 |
|------|-----|
| **地址** | `https://business-api.tiktok.com/open_api/v1.3/business/video/list/` |
| **方法** | GET |

### Header

| 字段 | 类型 | 描述 |
|------|------|------|
| Access-Token | string | **必填**。经 TikTok 创作者授权的访问令牌。若想获取访问令牌，需使用 `/tt_user/oauth2/token/` 接口。 |

### 参数

请将下列参数作为查询字符串进行传递。

| 字段 | 类型 | 描述 |
|------|------|------|
| business_id | string | **必填**。TikTok 账户的应用唯一识别 ID。您需将 `/tt_user/oauth2/token/` 接口返回的 `open_id` 字段值传给本字段。 |
| fields | string[] | 请求字段。若不进行设置，仅返回默认字段。默认值：`["item_id"]`。若您想请求多个数据字段，您需在 fields 的值中包含 `"item_id"`。否则，可能出现报错。示例：`["item_id", "create_time"]`。 |
| filters | object | 对结果集应用的筛选条件。 |
| cursor | integer | 分页光标。如果返回参数 `has_more` 为 `true`，请将返回中此参数中的光标值传递到后续请求，以获取下一页结果。默认值：当前时间，采用 Epoch/Unix 时间戳，以毫秒为单位。 |
| max_count | integer | 每页返回的最大视频数。默认值：`10`。最大值：`20`。 |

### fields 支持字段

| 字段 | 描述 | 所需权限 |
|------|------|----------|
| item_id | 帖子的唯一标识符 | video.list |
| media_type | 帖子类型 | video.list |
| thumbnail_url | 帖子预览缩略图 URL | video.list |
| share_url | 帖子的可分享 URL | video.list |
| embed_url | 帖子的可嵌入 URL | video.list |
| caption | 帖子的字幕/描述 | video.list |
| video_duration | 帖子时长（以秒为单位） | video.list |
| likes | 点赞数。帖子获得的总点赞数 | video.list |
| comments | 评论数。帖子获得的总评论数 | video.list |
| shares | 分享数。帖子被分享的总次数 | video.list |
| favorites | 收藏数。帖子被收藏的总次数 | video.list |
| create_time | 帖子发布的日期和时间（Unix/epoch 格式） | video.list |
| reach | 触达率。表示至少观看过一次已发布内容的用户 | video.list |
| video_views | 观看次数。视频被观看的总次数 | video.list |
| total_time_watched | 总观看时长。表示用户观看视频帖子的总时长 | video.insights |
| average_time_watched | 平均观看时长。表示用户观看视频帖子的平均时长 | video.insights |
| full_video_watched_rate | 完播率。表示看完此视频帖子的用户的百分比 | video.insights |
| new_followers | 新粉丝数。关注您账号的新粉丝总数 | video.insights |
| profile_views | 个人主页访问量（仅企业号） | video.insights |
| website_clicks | 网站点击数（仅企业号） | video.insights |
| phone_number_clicks | 手机号码点击数（仅企业号） | video.insights |
| lead_submissions | 潜在客户提交次数（仅企业号） | video.insights |
| app_download_clicks | 应用下载链接点击数（仅企业号） | video.insights |
| email_clicks | 邮箱点击数（仅企业号） | video.insights |
| address_clicks | 地址点击数（仅企业号） | video.insights |
| video_view_retention | 观众留存率 | video.insights |
| impression_sources | 流量来源 | video.insights |
| audience_genders | 性别分布 | video.insights |
| audience_countries | 热门国家/地区 | video.insights |
| audience_cities | 热门城市 | video.insights |
| audience_types | 观众类型分布 | video.insights |
| engagement_likes | 互动点赞 | video.insights |

### filters 对象

| 字段 | 类型 | 描述 |
|------|------|------|
| video_ids | string[] | 用于筛选洞察信息的帖子 ID 列表。示例：`["6995316737801538821", "8015388216995316737"]`。 |
| ad_post_only | boolean | 仅当传入 `video_ids` 时生效。是否从指定的视频列表中筛选已授权给广告主用于创建 Spark Ads 的视频。支持的值：`true`、`false`。默认值：`false`。 |

## 返回

### Header

这些 header 很重要，可用于记录问题报告和故障排查信息。

| 字段 | 类型 | 描述 |
|------|------|------|
| Date | string | 收到返回时的 (GMT) 日期和时间。示例：`Fri, 13 Aug 2021 08:04:42 GMT` |
| X-Tt-Logid | string | 接口请求的唯一标识符。 |

### Body

| 字段 | 类型 | 描述 |
|------|------|------|
| request_id | string | 接口请求的唯一标识符。请记录此字段，用于所有接口请求。 |

| data | object | 返回数据。 |
| data.videos | object[] | 帖子列表，包括展示在账户主页的原生帖子，以及"只作为广告展示"的帖子。 |

### video_view_retention 对象

| 字段 | 类型 | 描述 |
|------|------|------|
| second | string | 视频时长中的某一秒。 |

| 字段 | 类型 | 描述 |

### audience_countries 对象

| 字段 | 类型 | 描述 |
|------|------|------|
| country | string | ISO 3166-1 两位字母国家/地区代码。 |
| percentage | float | 从某一国家/地区注册的受众百分比。 |

### audience_cities 对象

| 字段 | 类型 | 描述 |
|------|------|------|
| city_name | string | 城市名称。示例：`US Cincinnati`。 |
| percentage | float | 某一城市关联的观众百分比。 |

### audience_types 对象

| 字段 | 类型 | 描述 |
|------|------|------|
| type | string | 观众类型。枚举值：`NEW_VIEWER`（新观众）、`RETURN_VIEWER`（回看观众）、`FOLLOWER_PERCENT`（粉丝）、`NON_FOLLOWER_PERCENT`（非粉丝）。 |
| percentage | float | 此观众类型关联的观众百分比。 |

### engagement_likes 对象

| 字段 | 类型 | 描述 |
|------|------|------|
| second | string | 视频时长中的某一秒。 |
| percentage | float | 在当前秒点赞视频的观众占比。 |

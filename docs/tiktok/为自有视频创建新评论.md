示例
为自有视频创建新评论
您可以使用本接口为自有TikTok 账号所发布原生视频创建新的评论。

注意

为了防止评论被系统标记为垃圾评论并因此隐藏，需避免在短时间内发布大量内容高度相似的评论。如果评论被标记为垃圾评论，您将不会收到 comment_action 为 set_to_public 的 comment.update webhook 事件通知。
评论 webhook 事件 comment.update 使您能够在自有 TikTok 账号下的任一公开视频下收到新评论的五分钟内收到通知。若想订阅评论 webhook ，请查看订阅评论更新事件。

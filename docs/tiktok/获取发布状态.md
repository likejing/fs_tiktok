# 获取发布状态

获取 TikTok 帖子的发布状态。

您可以使用本接口获取单个 TikTok 视频帖子或照片帖子的发布状态。

---

## 使用前需知

您需先使用 `/business/video/publish/` 或 `/business/photo/publish/` 生成一个帖子发布任务并从返回中获取 `share_id`。

---

## 请求

| 项目 | 值 |
|------|-----|
| **地址** | `https://business-api.tiktok.com/open_api/v1.3/business/publish/status/` |
| **方法** | GET |

### Header

| 字段 | 类型 | 描述 |
|------|------|------|
| Access-Token | string | **必填**。经 TikTok 创作者授权的访问令牌。若想获取访问令牌，需使用 `/tt_user/oauth2/token/` 接口。 |

### 参数

| 字段 | 类型 | 描述 |
|------|------|------|
| business_id | string | **必填**。TikTok 账户的应用唯一识别 ID。您需将 `/tt_user/oauth2/token/` 接口返回的 `open_id` 字段值传给本字段。 |
| publish_id | string | **必填**。帖子发布任务的唯一标识符。您需将 `/business/video/publish/` 或 `/business/photo/publish` 接口返回的 `share_id` 字段值传给本字段。 |

---

## 示例

```bash
curl --location --request GET 'https://business-api.tiktok.com/open_api/v1.3/business/publish/status/?business_id={{business_id}}&publish_id={{publish_id}}' \
--header 'Access-Token: {{Access-Token}}'
```

---

## 返回

| 字段 | 类型 | 描述 |
|------|------|------|
| code | number | 返回码。完整返回码列表及描述，参见 附录 - 返回码。 |
| message | string | 返回信息。更多信息参见 附录 - 返回码。 |
| request_id | string | 请求的日志 ID，唯一标识一个请求。 |
| data | object | 返回数据。 |
| data.status | string | TikTok 帖子的发布状态。枚举值见下表。 |
| data.post_ids | string[] | 仅当 `status` 为 `PUBLISH_COMPLETE` 且帖子公开可见时返回本字段。发布的 TikTok 帖子的 ID 列表。 |
| data.reason | string | 仅当 `status` 为 `FAILED` 时返回本字段。发布失败的原因。 |

### status 枚举值

| 值 | 描述 |
|-----|------|
| PROCESSING_DOWNLOAD | 正在从 URL 中提取内容 |
| PUBLISH_COMPLETE | 帖子已通过审核且发布成功 |
| FAILED | 帖子发布出现错误，帖子发布失败 |
| SEND_TO_USER_INBOX | 帖子草稿上传成功，系统已将相应通知发至创作者的收件箱中 |

> **注意**
> 
> - 帖子 ID 的数据处理可能长达 3 分钟。若未直接返回帖子 ID，需等待 3 分钟后重试。
> - 您可将 `post_ids` 返回的 ID 列表传入 `/business/video/list/` 中的筛选字段 `video_ids`，从而获取这些帖子的指标数据。
> - 若想获取失败原因的具体描述，可查看失败原因附录。

---

## 示例

### 发布成功的帖子

```json
HTTPS/1.1 200 OK
{
    "code": 0,
    "message": "OK",
    "request_id": "{{request_id}}",
    "data": {
        "post_ids": [
            "{{post_id}}"
        ],
        "status": "PUBLISH_COMPLETE"
    }
}
```

### 发布失败的帖子

```json
HTTPS/1.1 200 OK
{
    "code": 0,
    "message": "OK",
    "request_id": "{{request_id}}",
    "data": {
        "reason": "frame_rate_check_failed",
        "status": "FAILED"
    }
}
```

# TikTok 账户授权

## 前提

使用账号 API 前，开发者需要从商家获取管理商家账户的授权。

### 前提条件

- 已创建 TikTok For Business 账号。欲了解更多详情，请查看创建 TikTok For Business 账号。
- 已注册成为开发者。欲了解更多详情，请查看注册成为开发者。
- 已创建开发者应用，应用的权限范围需包含"TikTok Accounts"下账号 API 接口的权限。欲了解更多详情，请查看创建开发者应用。

## 步骤

### 步骤 1：分享授权 URL

开发者将授权 URL 分享给 TikTok 账号用户。若想获取该 URL，可导航至：

**应用管理 > App Detail > 基本信息 > TikTok账户授权URL**

![TikTok账户授权URL](images/tiktok_auth_url.png)

> **注意**
> 
> 若 TikTok 账号用户之前已经为该开发者应用授权过相同的权限，第 2 步中的权限范围审核和批准页面将被跳过，TikTok 账号用户将直接重定向到重定向 URL。
> 
> 若想禁用针对已授权的 TikTok 账户用户的自动重定向机制，开发者需要在与 TikTok 账号用户分享 URL 之前，在 TikTok 账户授权 URL 末尾手动添加 `&disable_auto_auth=1`。
> 
> 例如，如果原授权 URL 是：
> ```
> https://www.tiktok.com/v2/auth/authorize?{parameters}
> ```
> 
> 开发者应分享添加了禁用参数的：
> ```
> https://www.tiktok.com/v2/auth/authorize?{parameters}&disable_auto_auth=1
> ```

### App 标志要求

为确保用户授权时无报错出现，需为您的开发者 App 上传 App 标志图片，该图片将在授权时展示给用户。

**图片要求：**
- 格式：JPG、JPEG 或 PNG
- 分辨率：不超过 512 × 512px

若未上传 App 标志图片，用户在授权时可能会看到报错页面。

> **提示**
> 
> 若您无法在 **应用管理 > App Detail > 基本信息** 中找到 TikTok 账户授权 URL，可导航至 **授权 > 权限范围**。您需确保您为开发者应用启用了"TikTok Accounts"权限。

### State 参数（安全机制）

> **注意**
> 
> 为安全起见，您可以向授权 URL 添加一个唯一的 `state` 参数，以此作为防御 CSRF 攻击的机制。在用户重定向后，该参数将作为查询参数回传至您的应用。

## 重定向 URL 的格式规则

### 主要规则

- 每个开发者应用程序最多可以配置 **10 个** TikTok 账户主重定向 URL
- 重定向 URL 启用后会自动生成一个新的 TikTok 账户授权 URL
- 系统仅支持启用一个重定向 URL，启用状态的重定向 URL 用红色标记
- 仅存在一个 TikTok 重定向 URL 时，默认启用该 URL
- 若存在多个重定向 URL，可通过点击想启用的 URL 来进行启用

### TikTok 账户持有人重定向 URL 格式规则

为您的开发者应用指定 TikTok 账户持有人重定向 URL 时，需遵循以下格式规则：

| 序号 | 规则 | 正确示例 | 错误示例 |
|------|------|----------|----------|
| 1 | URL 必须为绝对地址，且以 `/` 结尾 | `https://dev.example.com/auth/callback/` | `https://dev.example.com/auth/callback` (缺少结尾 `/`) <br> `/auth/callback/` (缺少架构和域) |
| 2 | URL 应为静态地址，且不允许使用参数 | `https://dev.example.com/auth/callback/` | `https://dev.example.com/auth/callback/?id=1` (包含查询参数 `?id=1`) |
| 3 | URL 不可包含锚点 `#` | `https://dev.example.com/auth/callback/` | `https://dev.example.com/auth/callback/#1` (包含锚点 `#1`) |
| 4 | URL 必须以 `https://` 为开头 | `https://dev.example.com/auth/callback/` | `http://dev.example.com/auth/callback/` (使用 `http` 而非 `https`) |
| 5 | URL 不能包含端口 | `https://dev.example.com/auth/callback/` | `https://dev.example.com:3000/auth/callback/` (包含端口号 `:3000`) |
| 6 | 注册的 URI 长度应为 10 到 512 个字符 | N/A | N/A |

## 重定向 URL 的迁移指南

若想迁移 TikTok 账户持有人重定向 URL，请遵循以下步骤：

### 步骤 1：清理 URL

删除重定向 URL 中路径末尾可能存在的所有（由 `?` 符号表示的）查询参数或（由 `#` 符号表示）片段。您的 URL 应该以斜杠 `/` 结尾。

### 步骤 2：使用 State 参数替代查询参数

如果您从重定向 URL 中删除了查询参数，但想实现相同的效果，请在 TikTok 账户持有人授权 URL 中使用 `state` 参数。这涉及将查询参数编码为 JSON 对象，并将它们作为 `state` 参数的值包含在授权 URL 中。

**示例 1：**

- 原始 TikTok 账户持有人重定向 URL：`https://www.tiktok.com/photo?source=tiktok`
- 查询参数：`?source=tiktok`
- 要添加到 TikTok 账户授权 URL 中的编码后的 state 参数：`&state={"source":"tiktok"}`

**示例 2：**

- 原始 TikTok 账户持有人重定向 URL：`https://www.tiktok.com/photo?source=tiktok&platform=web`
- 查询参数：`?source=tiktok&platform=web`
- 要添加到 TikTok 账户授权 URL 中的编码后的 state 参数：`&state={"source":"tiktok","platform":"web"}`

### 步骤 3：解码 State 参数

在重定向 URL 中获取到授权码后，请从 TikTok 账户授权 URL 中的 `state` 参数中提取查询参数值。这涉及将 `state` 参数中的 JSON 编码字符串解码为字典或对象，然后访问该字典中特定键的值。

**Python 解码示例：**

```python
import json
from urllib.parse import unquote

state_value = '%7B%22source%22%3A%22tiktok%22%7D'
state = unquote(state_value)
state_dict = json.loads(state)
source = state_dict.get('source')
print(state_dict)

# Output: {'source': 'tiktok'}
```

## 步骤 2：用户审核批准

TikTok 账号用户审核批准授权请求。TikTok 账号用户可以在 TikTok 应用内随时撤销授权。

> **提示**
> 
> 若 TikTok 账号用户无法看到权限范围审核和批准页面，并被重定向到其他页面，这可能是由于针对已授权的 TikTok 账户用户的自动重定向机制。若想了解如何禁用自动重定向机制，请参阅步骤 1 中的相关说明。

---

## 步骤 3：获取授权码

TikTok 账号用户为应用请求的权限范围进行授权后，会跳转至应用指定的回调地址，该地址包含作为附加参数的授权码（若一开始添加了 `state` 参数，地址还会包含 `state` 参数）。

应用回调地址可通过以下路径查看：

**应用管理 > App Detail > 基本信息 > TikTok 账户持有人重定向 URL**

> **重要**
> 
> 授权码（`auth_code`）有效时间为 **10 分钟**，且仅可使用一次。过期后，您需要重新进行授权流程来获取一个新的授权码。

---

## 步骤 4：获取访问令牌

开发者通过使用（用户跳转后作为参数添加的）授权码，可向 `/tt_user/oauth2/token/` 接口发送请求，以获取访问令牌。

详细接口说明请参阅 [访问令牌API文档](./访问令牌.md)。
